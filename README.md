# Turbo LEV CRM

Операційна CRM-система для СТО **Turbo LEV**.

## Мета
Єдина система для шляху клієнта й автомобіля: від першої заявки до діагностики, погодження, закупівлі, ремонту, контролю якості, оплати, видачі та aftersales.

## Базові принципи
- CRM — єдине джерело фактичного статусу.
- Кожен етап має відповідального, next action і blocker.
- WorkOrder створюється тільки після підтвердженої діагностики.
- Деталі замовляються тільки після підтвердженої оплати.
- Додаткові платні роботи — тільки через нове погодження.
- READY — тільки після QC.
- Видача — тільки після повної оплати.
