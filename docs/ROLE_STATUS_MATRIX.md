# Turbo LEV — статуси та відповідальні ролі

Канонічне правило: **сервіс-менеджер веде клієнта й Замовлення-наряд; механік виконує діагностику та ремонт; Майстер зміни проводить QC; повна оплата передує статусу «Готовий до видачі».**

| Статус | Основна роль | Обов’язкова дія | Наступний нормальний статус |
|---|---|---|---|
| Записаний | Продажі / сервіс-менеджер | Підтвердити запис | Приїхав |
| Приїхав | Сервіс-менеджер | Оформити авто, призначити механіка | Очікує діагностики |
| Механік проводить діагностику | Автомеханік | Зафіксувати перевірки й технічний висновок | Діагностику прийнято |
| Кошторис і підбір | Сервіс-менеджер (+ підборщик за призначенням) | Роботи, деталі, допродаж | Очікує погодження |
| Очікує погодження клієнта | Сервіс-менеджер | Погодити з клієнтом | Очікує запчастини / Готовий до ремонту |
| Очікує запчастини | Сервіс-менеджер або підборщик | Підібрати, замовити, отримати | Готовий до ремонту |
| Готовий до ремонту | Сервіс-менеджер | Передати призначеному механіку | У ремонті |
| У ремонті | Автомеханік | Старт / пауза / завершення призначених робіт | Очікує контроль майстра зміни |
| Пауза / проблема | Механік + сервіс-менеджер | Усунути блокер | У ремонті / погодження / деталі |
| Очікує контроль майстра зміни | Майстер зміни | QC PASS/FAIL | Очікує повну оплату / Доопрацювання |
| Доопрацювання | Механік | Усунути зауваження | У ремонті → QC |
| Очікує повну оплату | Сервіс-менеджер (контроль) + бухгалтер/каса (проведення) | Закрити баланс | Готовий до видачі |
| Готовий до видачі | Сервіс-менеджер | Видати автомобіль | Закритий / виданий |

## Межі ролей
- **SERVICE_ADVISOR:** оформлення, комунікація, фінальний кошторис, погодження, допродаж, підбір і замовлення деталей, контроль оплати, видача.
- **MECHANIC:** тільки призначені діагностики й ремонт; не проводить QC і не погоджує кошторис з клієнтом.
- **SHIFT_MASTER:** проводить і підписує QC; не проводить оплату і не змінює кошторис.
- **PARTS_SPECIALIST:** делегований підбір/закупівлі.
- **ACCOUNTANT:** проводить оплату; не змінює сервісний статус вручну.
- **STATION_MANAGER:** операційний контроль станції, але не підміняє Майстра зміни як виконавця QC.
- **SALES / HEAD_OF_SALES:** воронка, клієнт до запису, попередній прорахунок; фінальний кошторис ЗН — не їхня зона.
