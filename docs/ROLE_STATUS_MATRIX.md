# Turbo LEV — матриця статусів і відповідальності

Канонічне правило: сервіс-менеджер веде клієнта і ЗН; механік виконує діагностику/ремонт; майстер зміни проводить QC; готовність до видачі настає тільки після повної оплати.

| Етап / статус | Основна роль | Дія | Наступний статус | Блокер |
|---|---|---|---|---|
| Записаний | Сервіс-менеджер / продажі | Підтвердити запис | Приїхав | клієнт не приїхав |
| Приїхав | Сервіс-менеджер | Оформити авто, призначити діагностику | Очікує діагностики | немає механіка |
| Діагностика триває | Автомеханік | Виконати перевірки, зафіксувати висновок | Діагностику підтверджено | технічне рішення |
| Кошторис / роботи / деталі | Сервіс-менеджер (+ підборщик за призначенням) | Сформувати роботи, підібрати деталі, допродати | Очікує погодження | неповний кошторис |
| Очікує погодження клієнта | Сервіс-менеджер | Погодити з клієнтом | Очікує запчастини / Готовий до ремонту | погодження клієнта |
| Очікує запчастини | Сервіс-менеджер або підборщик | Замовити/отримати | Готовий до ремонту | деталі відсутні |
| Готовий до ремонту | Сервіс-менеджер | Передати призначеному механіку | У ремонті | механік/пост/деталі/погодження |
| У ремонті | Автомеханік | Почати/виконати/завершити роботи | Очікує контроль якості | додаткові роботи/деталі |
| Призупинений / проблема | Автомеханік + сервіс-менеджер | Усунути блокер | У ремонті / погодження / деталі | причина паузи |
| Очікує контроль якості | Майстер зміни | Провести QC | Очікує оплату / Доопрацювання | QC не пройдено |
| Доопрацювання | Автомеханік | Усунути зауваження QC | У ремонті → QC | зауваження майстра зміни |
| Очікує оплату | Сервіс-менеджер + бухгалтер/каса | Отримати повну оплату | Готовий до видачі | залишок > 0 |
| Готовий до видачі | Сервіс-менеджер | Видати автомобіль | Закритий / виданий | нульовий баланс + QC |
| Закритий / виданий | Сервіс-менеджер | Післяпродажний супровід | — | — |

## Ролі
- **Сервіс-менеджер (SERVICE_ADVISOR):** клієнт, оформлення, кошторис, погодження, допродаж, підбір/закупівля деталей, контроль оплати, видача.
- **Автомеханік (MECHANIC):** тільки призначені діагностики та роботи; старт/пауза/завершення ремонту.
- **Майстер зміни (SHIFT_MASTER):** незалежний QC, PASS/FAIL, повернення на доопрацювання.
- **Підборщик запчастин (PARTS_SPECIALIST):** делегований підбір/закупівлі в межах станції; scope може бути розширений власником.
- **Бухгалтер (ACCOUNTANT):** проведення оплат і фінансовий облік; сервіс-менеджер бачить стан оплати, але не отримує право проводити фінансові операції.
- **Завідувач станцією (STATION_MANAGER):** операційний нагляд та право втручання в межах своєї станції.
- **Власник / виконавчий директор:** повний управлінський доступ, але не є операційною відповідальною роллю конкретного етапу.
