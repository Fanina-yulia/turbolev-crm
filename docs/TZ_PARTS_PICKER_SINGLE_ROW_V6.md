# TURBO LEV CRM — ТЗ V6: компактний службовий рядок підбору запчастин

Дата: 16.09.2026
Модуль: parts-inventory
Екран: popup «Підбір деталі» (`PartsSelectionWorkspaceV4`)

## Мета

Зменшити вертикальну висоту popup без втрати робочих дій менеджера.

## Вимоги

1. Повністю прибрати з UI окремий службовий рядок з плашками:
   - «Точна сумісність не підтверджена» / «VIN-каталог підтверджено»;
   - «N API підключено»;
   - «Розпізнано: … · …%».
2. Не змінювати business logic пошуку, fitment, supplier cascade або manual-confirmation gate.
3. На desktop в одному горизонтальному рядку відображати:
   - фільтр постачальника;
   - кількість знайдених позицій;
   - сортування Бренд / Ціна / Наявність / Термін;
   - checkbox «Я вручну перевірив сумісність непідтверджених позицій для цього автомобіля», коли він потрібний.
4. Checkbox залишається функціональним і обов’язковим для додавання непідтверджених/assembly-пропозицій.
5. На вузьких екранах дозволяється окремий адаптивний рядок для checkbox, щоб не ламати мобільний інтерфейс; redundant fitment badges не повертаються.
6. Не змінювати структуру результатів пошуку, кошик, ціни, supplier evidence або API.

## Acceptance

- `.fitmentLine` не відображається.
- desktop: `resultToolbar` і `manualConfirm` займають один grid-row;
- пошук, сортування, supplier filter та manual confirmation працюють як раніше;
- production build зелений;
- production deployment `READY`;
- після релізу немає нових runtime error clusters.
