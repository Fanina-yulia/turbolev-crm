# TURBO LEV — live застосування налаштувань кабінету механіка

## Мета
Будь-який вибір у панелі «Налаштування кабінету» повинен застосовуватися до кабінету механіка в той самий момент натискання, без кнопки «Зберегти», без закриття панелі та без перезавантаження сторінки.

## Поведінка
- тема застосовується синхронно до кореня кабінету;
- розмір шрифту застосовується синхронно через data-атрибути;
- щільність застосовується синхронно через data-атрибути та semantic CSS vars;
- кольорова гама застосовується синхронно через `--m-orange` / `--m-orange-soft`;
- вибір одразу записується в localStorage;
- `system` реагує на зміну системної теми;
- при монтуванні/перемонтуванні кореня кабінету останні збережені параметри повторно застосовуються;
- legacy `turbolev:mechanic-theme` синхронізується для сумісності з поточним кабінетом.

## Не змінюється
Workflow, API, діагностика, сканер, сповіщення та бізнес-логіка механіка.
